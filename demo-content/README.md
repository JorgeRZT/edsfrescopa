# Demo content

Snapshot of the Fréscopa site in da.live (`jorgerzt/edsfrescopa`), exported with `npm run export:content`. Seed it into a new da.live site with `ORG=<org> SITE=<site> npm run seed:content`. See the main [README](../README.md#use-this-repo-as-a-template-code--demo-content).

This folder is excluded from the code bus (`.hlxignore`). Do not edit it by hand: edit in da.live and export again.
